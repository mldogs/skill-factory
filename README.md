# Skill Factory

Скиллы для [Claude Code](https://claude.com/claude-code), которые превращают «длинный» контент в **интерактивные двуязычные (RU/EN) учебные страницы** — самодостаточные HTML-файлы, открывающиеся двойным кликом, без сервера и без внешних зависимостей.

| Скилл | Вход | Выход |
|---|---|---|
| **book-deepdive** | Целая книга (название или текст) | `books/<slug>/` — фактчекнутый разбор: структура по частям, концепты с inline-SVG/CSS-визуалами, иллюстрации, глоссарий с поиском, Q&A для активного повторения |
| **podcast-deepdive** | Один YouTube-эпизод (URL) | `podcasts/<slug>/` — разбор «с голосами»: спикеры, тайм-лайн глав с deep-link в YouTube, атрибутированные цитаты (заземлены по транскрипту), карточки споров, глоссарий, Q&A |

Оба скилла работают по одной схеме: **multi-agent анализ** (map → анализ по секциям → adversarial-проверка фактов → синтез) → единый JSON-источник истины (`book.json` / `podcast.json`, контракт принуждается Draft-07-валидатором) → перевод RU↔EN → генерация иллюстраций → рендер страницы.

## Установка

Скопируйте нужные скиллы в `.claude/skills/` вашего проекта (или в `~/.claude/skills/` для всех проектов):

```bash
git clone https://github.com/mldogs/skill-factory
mkdir -p your-project/.claude/skills
cp -R skill-factory/book-deepdive skill-factory/podcast-deepdive your-project/.claude/skills/
```

После перезапуска Claude Code скиллы доступны как `/book-deepdive` и `/podcast-deepdive` — или естественной фразой: «разбери книгу …», «сделай разбор подкаста <url>».

## Пред-реквизиты

- **Claude Code** с доступом к инструменту Workflow (анализ построен на multi-agent workflow-скриптах).
- **`uv`** — валидаторы (`validate_book.py`, `validate_podcast.py`) тянут `jsonschema` через PEP 723 metadata.
- **`yt-dlp`** (только для подкастов) — выкачивание субтитров YouTube.
- **`.env` в корне проекта** (для генерации иллюстраций):
  ```
  OPEN_ROUTER_API_KEY=sk-or-...
  IMG_MODEL=google/gemini-3.1-flash-image-preview   # опционально
  IMG_STYLE=...                                     # опционально, переопределяет стиль по умолчанию
  ```
  Картинки кешируются по имени файла — повторный прогон бесплатен. Без ключа всё работает, кроме иллюстраций-метафор (CSS/SVG-визуалы рисуются без API).

## Как это устроено

- **Один JSON — источник истины.** Анализ пишет `book.json` / `podcast.json`; страницу рендерит детерминированный Python-скрипт (`scripts/build_page.py`). Перегенерация страницы никогда не теряет данные.
- **Заземление.** Цитаты подкастов сверяются с транскриптом посимвольно; книги проходят adversarial-проверку фактов отдельными агентами.
- **Гибридные визуалы.** Точные/структурные идеи → inline SVG/CSS-анимация; метафоры → сгенерированная иллюстрация в едином стиле.
- **Двуязычность.** Русский — основной, английский — из `i18n/*.json`; переключатель RU/EN на странице, выбор запоминается в `localStorage`.
- **Атомарные публикации.** Черновики (`.draft`) заменяют финальный JSON только после прохождения валидатора.

Подробности — в `SKILL.md` каждого скилла.
